# 国产化不动产登记系统（bdc-master5.0 + bdc-web4.0）编码风格总结

> 本文档基于对后端 `bdc-master5.0` 与前端 `bdc-web4.0` 全量代码的深度分析，提炼出可复用的编码风格规范，供新项目直接套用。
> 分为四部分：一、总体架构与技术基线；二、后端编码规范；三、前端编码规范；四、沿用与规避清单。

---

## 一、总体架构与技术基线

### 1.1 架构形态

- **微服务架构**：Spring Cloud Alibaba（Nacos 注册 + 配置中心）+ OpenFeign 服务间调用 + 自研网关（JWT 统一鉴权、白名单、文档聚合）
- **前后端分离**：前端 Vue3 + Vite + TS，后端 Spring Boot 3.5 微服务集群，通过多网关前缀（`/api`、`/bpmapi`、`/formapi`、`/tyyw`）代理区分微服务
- **国产化适配**（信创特色，新项目必保留）：
  - 数据库多方言适配：MySQL / **达梦 DM** / PostgreSQL / **瀚高 HGDB**（驱动均在 pom 统一管理，SQL 写法需跨库兼容）
  - 运行时配置托管 Nacos，Maven profile 按部署环境（地方定制项目）切换 namespace
  - 地方定制以独立模块（`bdc-api-*`）形式叠加，不污染主干代码

### 1.2 技术选型清单

**后端：**

| 类别 | 选型 |
|---|---|
| JDK / 核心框架 | Java 21 + Spring Boot 3.5.x + Spring Cloud 2025.x + Spring Cloud Alibaba |
| ORM | MyBatis-Plus 3.5（BaseMapper + ServiceImpl + 分页插件） |
| 数据源 | Druid + dynamic-datasource 多数据源（`@DS` 切换） |
| 缓存/锁 | Redis + Redisson（分布式锁） |
| MQ / 任务 | RocketMQ + XXL-Job |
| 工作流 | Flowable 7 |
| 文档 | knife4j（springdoc-openapi v3 注解体系，`/doc.html`） |
| Excel | EasyExcel / FastExcel（统一收敛到 FastExcel） |
| 工具库 | Hutool（全局依赖，优先使用）、commons-lang3、fastjson2 |

**前端：**

| 类别 | 选型 |
|---|---|
| 框架 | Vue 3.5（组合式 API + `<script setup lang="ts">`） |
| 构建 | Vite 7 + @vitejs/plugin-vue |
| UI 库 | **Ant Design Vue 4** + @ant-design/icons-vue |
| 状态管理 | Pinia（选项式 store） |
| HTTP | axios 自封装 `RequestHttp` 类，单例导出 `defHttp` |
| 样式 | Less（scoped）+ antd token 主题 |
| 其他 | crypto-js/jsencrypt（密码加密）、xlsx-js-style（导出）、mitt、lodash-es、pinyin-pro |

## 二、后端编码规范（bdc-master5.0 风格）

### 2.1 工程结构与分层

```
项目根/
├── zrzy-common/          # 公共模块（base-core: Result/常量/异常/工具/AOP；bpm7/rocketmq/xxljob 等能力子模块）
├── zrzy-module-<域>/     # 业务微服务（bdc/system/form/report/logic/cdc...）
│   └── org.mapgis.modules.<域>/
│       ├── controller/   # XxxController
│       ├── service/      # IXxxService 接口
│       │   └── impl/     # XxxServiceImpl（复杂业务再按登记类型拆子包/策略类）
│       ├── mapper/       # XxxMapper extends BaseMapper
│       │   └── xml/      # MyBatis XML 与 Java 同包（src/main/java 下，靠 pom resources 配置打包）
│       ├── entity/       # 表实体（无后缀，与表名驼峰对应）
│       ├── dto/          # XxxDto 传输对象
│       ├── model/        # XxxModel 视图模型（本项目不用 vo 包）
│       ├── client/       # XxxFeignClient（@FeignClient 跨服务调用）
│       └── util/ config/
└── zrzy-server-cloud/    # 网关（bdc-gateway）
```

要点：
- 启动类统一 `@SpringBootApplication(exclude = SecurityAutoConfiguration.class)` + `@EnableFeignClients` + `@ComponentScan`（含 `com.core`），启动日志打印 `/doc.html` 地址
- Mapper 靠 `@Mapper` 注解扫描，不使用 `@MapperScan`
- 本地 yml 极薄（应用名 + Nacos 地址占位符 `@config.namespace@`），业务配置全部 `spring.config.import: optional:nacos:xxx.yml` 托管；公共配置抽 `bdc-share.yml` 共享

### 2.2 Controller 层模板

```java
/**
 * 登记簿
 *
 * @author zhangsan
 * @date 2024-12-18 10:33
 */
@Tag(name = "登记簿")                          // knife4j 中文文档注解
@RestController
@RequestMapping("/bdc/bdcDjb")                 // 路径 = /业务域/实体名驼峰
@RequiredArgsConstructor                       // 一律构造注入，禁止 @Autowired 字段注入
@Slf4j
public class BdcDjbController {
    private final IBdcDjbService bdcDjbService;

    @GetMapping("/list")
    @Operation(summary = "分页列表查询")
    public Result<IPage<BdcDjb>> queryPageList(@ParameterObject BdcDjb bdcDjb,
            @RequestParam(name = "pageNo", defaultValue = "1") Integer pageNo,
            @RequestParam(name = "pageSize", defaultValue = "10") Integer pageSize,
            HttpServletRequest req) {
        QueryWrapper<BdcDjb> queryWrapper = QueryGenerator.initQueryWrapper(bdcDjb, req.getParameterMap());
        return Result.OK(bdcDjbService.page(new Page<>(pageNo, pageSize), queryWrapper));
    }
}
```

- **统一返回**：`Result<T>`（success/message/code/result/timestamp/exceptionId），静态方法 `Result.OK(data)` / `Result.error(msg)`；状态码 200/500/510 集中在 `CommonConstant`
- **URL 动词式命名**：`/add`、`/edit`、`/delete`、`/list`、`/queryById`（不追求严格 REST）
- **分页**：MyBatis-Plus `Page<T>/IPage<T>`，不用 PageHelper；GET 查询用 `@ParameterObject` 实体直收 + `QueryGenerator.initQueryWrapper()`（请求参数自动转 QueryWrapper）
- **鉴权在网关**（JWT），Controller 不写权限注解；行级数据权限用自研 `@DataPermission` AOP

### 2.3 Service 层

```java
public interface IBdcDjbService extends IService<BdcDjb> { ... }

@Service
@RequiredArgsConstructor
@Slf4j
public class BdcDjbServiceImpl extends ServiceImpl<BdcDjbMapper, BdcDjb> implements IBdcDjbService {

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void register(DjbDto dto) {
        // 业务校验失败 → 抛友好异常，中文消息直达前端
        if (exists(dto.getYwh())) {
            throw new FriendlyException("该业务号已存在登记记录");
        }
        this.save(dto);
    }
}
```

- 接口命名 **`IXxxService`**（新项目统一执行，源项目存在少量失范）
- 事务注解一律 `@Transactional(rollbackFor = Exception.class)`，只放 Service 实现层
- 业务异常：`FriendlyException`（面向用户）/ `BusinessException`；全局 `@RestControllerAdvice` 异常处理器分类处理并**兜底异常入库（SysExceptionLog）+ 返回 exceptionId**，不外泄堆栈
- 复杂业务按业务类型拆分子 Service / 策略类，避免单类膨胀

### 2.4 Mapper 与 SQL

- Mapper 接口：`@Mapper public interface XxxMapper extends BaseMapper<Xxx>`，简单 CRUD 零 XML
- XML 中手写原生 SQL：`resultType` 直映实体（不用 resultMap），表别名 + 多表 JOIN + `<if>` 动态条件，**SQL 关键字大写、列名小写**
- SQL 必须跨库兼容（达梦/PG/瀚高），禁用 MySQL 专有函数
- 多数据源切换：`@DS("bdc")`，数据源名常量化于 `CommonConstant.DATA_SOURCE_XXX`

### 2.5 实体类模板

```java
@Data
@TableName("BDC_DJB")                       // 表名大写下划线
@Accessors(chain = true)
@Schema(description = "登记簿")
public class BdcDjb implements Serializable {
    private static final long serialVersionUID = 8187815548383658724L;

    /** 主键标识 */
    @TableId(type = IdType.ASSIGN_ID)       // 雪花 ID 为默认策略
    @JsonFormat(shape = JsonFormat.Shape.STRING)   // Long → String，防前端精度丢失
    private Long id0;

    /** 受理编号 */
    @Schema(description = "受理编号")
    private String slbh;

    /** 入库时间 */
    @JsonFormat(timezone = "GMT+8", pattern = "yyyy-MM-dd HH:mm:ss")
    @DateTimeFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private Date writetime;
}
```

- Lombok：`@Data` 必备，配 `@RequiredArgsConstructor`/`@Slf4j`/`@Accessors(chain = true)`
- 每个字段：单行 `/** 中文含义 */` 注释 + `@Schema` 中文描述
- 审计字段（createBy/createTime/updateBy/updateTime）抽 `BaseEntityRoot` 基类，`@TableField(fill = ...)` 自动填充；ID 策略有变体基类（雪花/自增）
- **领域字段用行业拼音缩写且与库表列名一致**（slbh=受理编号、ywh=业务号、bdcdyh=不动产单元号），不做翻译映射

### 2.6 命名与注释规范

| 类别 | 约定 |
|---|---|
| 类名 | `XxxController` / `IXxxService` / `XxxServiceImpl` / `XxxMapper` / 实体无后缀 / `XxxDto` / `XxxModel` / `XxxFeignClient` |
| 方法 | queryPageList / queryById / add / edit / delete / exportXls；业务方法可用拼音（getAndPrintIfNeeded） |
| 常量 | 全大写下划线，集中于 `CommonConstant`（interface 常量类 + `//region` 折叠分区 + 中文 javadoc） |
| 包名 | 全小写单层：controller/service/impl/mapper/entity/dto/model/client/config/util |

注释规范：
- 类头必带 javadoc：`业务名 + @author + @date（精确到分钟，代码生成器同时间戳生成五件套）`
- 公开方法必有中文 javadoc（含 @param/@return）
- **注释 100% 中文**；行内注释解释"为什么"而非"做什么"
- 常用 `//region xxx ... //endregion` 折叠分区组织大类

### 2.7 横切能力（common 模块标准件）

新项目应保留的自研组件清单：

| 组件 | 说明 |
|---|---|
| `Result<T>` | 统一返回包装 |
| `CommonConstant` | 状态码/数据源名/通用常量集中地 |
| `GlobalExceptionHandler` | 全局异常处理 + 异常入库 + exceptionId 追踪 |
| `@DataPermission` + `DataPermissionInterceptor` | SQL 拦截追加 tenant_id/system_id 过滤（多租户+行级数据权限） |
| `@Dict` + DictAspect | 字典翻译（`_dictText` 后缀字段） |
| `RedisUtil` / `RedisLockUtil` | 缓存 + Redisson 分布式锁封装 |
| `UserUtil` / `SecurityUtils` | 当前登录用户上下文 |
| `SqlFilter` | SQL 注入过滤 |
| `ExcelUtils` | 导入导出封装 |
| `DynamicDBUtil` | 动态注册数据源 |

## 三、前端编码规范（bdc-web4.0 风格）

### 3.1 目录结构

```
src/
├── api/          # 仅框架级 API（sys/user、sys/menu、sys/dict + model/ 类型目录）
├── assets/       # less/(全局样式) svg/ images/
├── components/   # 全局公共组件（cModal、cDrawer、table、input、SvgIcon、FileIcon...）
├── directives/   # 自定义指令（v-permission 按钮权限）
├── enums/        # 枚举（pageEnum / httpEnum / cacheEnum）
├── hooks/        # 组合函数（setting/useXxxSetting）
├── mock/         # 静态 JSON mock
├── router/       # index.ts + guard/ + helper/ + routes/ + types.ts + constant.ts
├── settings/     # projectSetting + initSetting（Nacos 远程配置加载）
├── store/        # index.ts + modules/（app/user/permission/tabs）
├── utils/        # auth/ bdc/ cache/ http/ cipher.ts dictUtils.ts is.ts
├── views/        # 按业务域分组（bdc/system/bpm/online/data/wwsjxt...）
└── main.ts       # bootstrap() 分步引导
```

要点：
- **views 按业务域分组**，域内页面入口统一 `index.vue`，子组件放 `components/`
- 业务 API"就近放置"：页面内 URL 写在组件内 `enum api {}`，可复用的放 `views/<模块>/utils/`；仅框架级接口进 `src/api/`
- 路径别名：`/@/ → src`、`/#/ → types`（新项目可回归 `@/`）
- `main.ts` 采用 `bootstrap()` 分步引导（Nacos 远程配置 → store → 全局组件 → 路由守卫），各模块提供 `setupXxx(app)` 工厂函数

### 3.2 组件（.vue）模板

```vue
<template>
  <a-table :dataSource="datalist" :loading="spinning">
    <template #bodyCell="{ column, record }">
      <template v-if="column.key === 'action'">...</template>
    </template>
  </a-table>
</template>

<script setup lang="ts">
  // SFC 固定顺序：template → script setup → style scoped less
  let props = defineProps({
    title: { type: String, default: '标题' },   // 运行时对象式，带默认值
  })
  const emit = defineEmits(['ok'])
  const datalist = ref<any[]>([])
  const spinning = ref(false)
  const loadData = async () => { ... }           // 列表加载统一命名 loadData
  const handleOk = () => emit('ok')              // 事件处理统一 handleXxx
</script>

<style scoped lang="less"></style>
```

- 全部组合式 API + `<script setup lang="ts">`；antd 表格统一用 `#bodyCell` 具名插槽渲染单元格
- **通用弹窗/抽屉组件模式（本项目核心特色）**：`import.meta.glob('/src/**/*.vue')` + `defineAsyncComponent(modules['/src/' + filePath + '.vue'])`，通过传文件路径字符串即可打开任意页面组件的弹窗，大幅减少样板代码

### 3.3 API 请求层

```ts
/** @description: 用户登录 */
export function loginApi(params) {
  return defHttp.post({ url: Api.getTokenApi, params }, { withToken: false })
}
```

- URL 用**文件内 `enum api {}` 集中声明**（非散落字符串、非常量对象）
- 统一调用签名：`defHttp.get({ url, params }, { withToken: true })`
- API 函数后缀 `Api`，每个函数带 `/** @description: xxx */` 中文 JSDoc
- token 刷新采用"单飞 + 旋转"模式（并发请求只触发一次刷新）
- 多网关前缀（/api、/bpmapi、/formapi）由 vite proxy 转发，环境变量 `VITE_GLOB_API_URL` 等管理

### 3.4 状态管理（Pinia）

```ts
export const usePermissionStore = defineStore({
  id: 'app-permission',                  // id 用 'app-xxx' 前缀
  state: (): PermissionState => ({ ... }), // 工厂函数带返回类型，类型为文件内 interface XxxState
  getters: { getMenuList() { ... } },     // getter 一律 getXxx
  actions: { async buildRoutesAction() { ... }, setXxx() { ... } }, // action 用 setXxx / xxxAction
})

// 组件外使用三件套
export function usePermissionStoreWithOut() {
  return usePermissionStore(store)
}
```

### 3.5 路由与权限

- 静态基础路由（basic.ts，LAYOUT + 懒加载）+ **后端菜单动态路由**（`buildRoutesAction()` 拉菜单 → helper 转换 → `addRoute()`）
- 守卫拆分文件：`guard/permissionGuard.ts`（白名单 + token + 动态路由）、`guard/stateGuard.ts`，在 `guard/index.ts` 汇总注册
- 路由常量集中 `src/enums/pageEnum.ts`（BASE_LOGIN/BASE_HOME）；扩展类型 `AppRouteRecordRaw` + meta（title/hideMenu/currentActiveMenu）
- 按钮级权限用自定义指令 `v-permission`

### 3.6 命名与注释规范

| 类别 | 约定 |
|---|---|
| 组件文件 | PascalCase（新项目统一；源项目存在 camelCase 混用） |
| 页面入口 | `index.vue`；列表页 `List.vue`；弹窗 `XxxModal.vue`、抽屉 `XxxDrawer.vue` |
| 全局组件 | kebab-case 注册，业务前缀 `c`（cModal/cDrawer/c-input） |
| 变量 | camelCase；响应式列表 `datalist`、加载态 `spinning` |
| 函数 | 事件 `handleXxx`、查询 `getXxx`、加载 `loadData`、查询 `searchData`、清空 `clear` |
| API 函数 | `xxxApi` 后缀 |
| 组合函数 | `useXxx`（useThemeSetting/useXxxStoreWithOut） |
| 枚举 | `XxxEnum`，成员 SCREAMING_SNAKE |
| 业务目录 | 拼音缩写（bdc/lpb/qlr/wwsjxt），与后端领域术语一致 |

注释规范：
- 中文注释主导；API/工具函数用块级 JSDoc（`@description` + 中文 `@param`），组件内用行内 `//` 中文短注释解释业务

### 3.7 样式规范

- Less 为唯一预处理器；组件内 `<style scoped lang="less">`
- 全局样式集中 `src/assets/less/`（base/form/table/transition），main.ts 统一引入
- 主题：antd4 token（`colorPrimary: '#5094F9'`）经 `a-config-provider :theme` 全局注入；支持全局字号配置、黑白模式等特殊主题

### 3.8 安全与其他特征

- 密码 AES 加密传输（jsencrypt/crypto-js），登录含租户选择、超时自动登出、锁屏
- 运行时配置从 Nacos 下发挂 `window.settingConfig`（`main.ts` 阻塞式拉取）
- 导出：xlsx-js-style（带样式 Excel）；打印：自研打印组件 + kkFile 在线预览
- Vite：函数式配置、gzip（>10KB）、svg 雪碧图、多前缀代理

## 四、沿用与规避清单

### 4.1 必须沿用的风格（项目基因）

1. **全中文注释 + 中文 API 文档**（@Tag/@Operation/@Schema、@description JSDoc）
2. **领域拼音缩写贯穿前后端**（slbh/ywh/bdcdyh 与数据库列名一致，不翻译）
3. 后端五件套代码生成（entity/dto/mapper/service/controller，类头 @date 精确到分钟）
4. 统一返回 `Result<T>` + 网关 JWT 鉴权 + 全局异常处理器（异常入库 + exceptionId）
5. MyBatis-Plus 全家桶（Page 分页、QueryGenerator、ServiceImpl、@DS 多数据源、雪花 ID Long→String）
6. `@DataPermission` 多租户/行级权限、@Dict 字典翻译等 common 标准件
7. 前端 `enum api {}` + `defHttp` 统一签名 + Pinia `getXxx/xxxAction/useXxxStoreWithOut` 三件套
8. 后端菜单动态路由 + `v-permission` 按钮权限 + 守卫四分目录
9. views 按业务域分组 + `index.vue` 入口 + `components/` 子组件
10. Nacos 配置中心 + Maven profile 多环境（地方定制走独立叠加模块）
11. 国产化多数据库兼容意识（SQL 写法跨达梦/PG/瀚高）
12. **antd 组件全局注册**：组件仅在 `registerGlobComp.ts` 注册一次，页面模板直接用 `<a-xxx>`；页面只允许导入 message/Modal/notification 等函数式 API（详见《AntDesignVue组件注册规范.md》）

### 4.2 应规避的历史坏味道（新项目规范化）

| 问题 | 新项目规范 |
|---|---|
| `I` 前缀、Model/Dto/VO 边界不统一 | 严格统一：`IXxxService` / `XxxDto`（入参出参）/ `XxxModel`（视图模型） |
| 大量注释保留的废弃代码、pom 注释依赖 | 废弃代码直接删除，交给 Git 历史 |
| `System.out.println` / `printStackTrace()` / `if(true)` | 一律用 `@Slf4j` log，禁止调试残留 |
| Controller 上标 @Transactional | 事务只放 Service 实现层 |
| 前端无 ESLint/Prettier，缩进引号混用 | 新项目必须配置 ESLint + Prettier + husky |
| `let` 声明不变的 ref、`any` 兜底、build 不跑类型检查 | `const` 优先；`build` 脚本含 `vue-tsc`；补齐类型声明 |
| defineProps 运行时对象式（新代码可改进） | 新组件统一 TS 类型泛型写法（`defineProps<{...}>()`） |
| API 返回值 `new Promise` 手动解包 | 使用泛型 `defHttp.get<T>()` 声明返回类型 |
| 组件文件大小写混用 | 统一 PascalCase，页面入口 `index.vue` |
| POI/EasyExcel/FastExcel 三代并存 | 统一收敛到一款（FastExcel） |
| TestController 等测试代码留在生产模块 | 测试接口只存在于 test 目录或独立 profile |
